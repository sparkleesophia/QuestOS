## ⚡ Core Features

- **Player HUD**: Dynamic Level (Novice Automator &rarr; Autonomous Sovereign), XP progress bar, active flame streaks, and total deep work hours logged.
- **Milestone Countdown Cards**: Live countdown timers for the 6-month agency target, driving test, and passport appointment.
- **Bust Procrastination (Quick Win)**: Instant 1-click modal that selects a 10–15 minute micro-task to break friction.
- **Daily Quest Checklist**: Mark tasks complete with confetti celebration, sound effects, floating XP rewards, and automatic level up checks.
- **Deep Work Focus Timer**: 25-minute Pomodoro & open stopwatch. Automatically awards **+10 XP bonus per 30 minutes** of deep work and logs time to individual quests.
- **n8n Automation Bridge**: Server-side webhook relay (`/api/n8n/dispatch`) that sends live event payloads to your n8n workflow (ready for Telegram/Discord bots or Notion sync).
- **Zero-Friction Persistence**: Works out of the box with `localStorage` and includes 1-click JSON backup export/import.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ (tested on Node v24)
- npm, pnpm, or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/sparkleesophia/QuestOS.git
cd QuestOS

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
